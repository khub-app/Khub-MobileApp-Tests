Follow-Through

Every finding gets triaged

A failure is diagnosed before it's reported — real app defect, automation flake, or environment noise, each handled differently.

New issues Found for the first time on a given APK build
Recurring app defects Real bugs in the Admin app, confirmed repeatedly
Waiting on a decision Needs dev or product input to resolve
Automation-side flakiness Stale RN elements, FAB speed-dial races — hardened in the suite, not the app
Environment / infra issues Emulator Wi-Fi validation, ADB/UiAutomator2 — outside the application itself
